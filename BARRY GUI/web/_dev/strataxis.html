The layer overlay was extended from the traces onto every image panel. That is right for a panel whose rows are channels — the CSD, a stacked time-frequency view — and wrong for one whose y axis is frequency. A single-channel spectrogram or scalogram sets rows_meta = None (analysis.py:705) and the band-power map has no "rows" key at all (analysis.py:972), so neither can say which channel a lane is. The overlay's fallback is "every selected channel, evenly spaced down the plot", which on those panels paints the layer colours straight across a frequency axis. This drives the real BARRY.strata.draw with a recording canvas and counts what it paints, for each shape of panel answer the server actually sends.
