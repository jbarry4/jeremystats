Sorting VACC files from your browser

A web page cannot log in to the VACC directly — browsers can't make SSH connections. To sort VACC files here, make that VACC storage look like a normal folder on this PC, then open it below.

Recommended options:

1. Map Netfiles / Research Storage as a drive — if your images live on a Netfiles share (/netfiles/<share>), map it as a network drive in Windows (This PC → Map network drive), then click Open the mapped folder below.

2. Mount VACC over SFTP — use a tool that mounts SSH storage as a drive letter (e.g. WinFsp + SSHFS-Win, or your file-transfer client's "mount"), log in with your NetID, then open that drive here.

3. Use the Python server version (Solid or Sputter Web.py) — it logs in with your NetID and does the sorting on the cluster, no drive-mapping needed.
