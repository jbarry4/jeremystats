About the Dentate Spike Sorter

A lightweight, fully in-browser tool for triaging candidate dentate-spike images. Open a folder and the app creates four subfolders — Dentate Spike, Garbage, Flag, and Flag for Deep Review. Each label places a copy of the current image into the matching subfolder while the original stays in the main folder, so your source set is never altered.

Keyboard shortcuts

  • 1/D — Dentate Spike  ·  2/G — Garbage
  • 3/F — Flag  ·  4/R — Flag for Deep Review
  • C — clear label  ·  Z — undo  ·  ←/→ — navigate
  • +/− — zoom  ·  0 — fit to view

Event summaries. The Export event summaries button writes one CSV into each category subfolder, listing just the event numbers (the last run of digits in each filename) in a single column, sorted ascending. Re-run it any time to refresh.

Everything is local: no server, no upload, nothing leaves your computer. Requires a Chromium-based browser (Chrome or Edge) for folder access.

Developed to support hippocampal electrophysiology research at the University of Vermont.
