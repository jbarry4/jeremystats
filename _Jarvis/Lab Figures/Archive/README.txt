Known correction (found 2026-11-23): the battery code converted contacts to micrometers at 50 um per
contact. These recordings are on an H3 probe, 20 um per contact, so every distance in um in the
folders above is 2.5 times too large (for example "DS1 sits 98-329 um farther out" is 39-132 um).
Ratios, correlations and P values do not change. The DS3 "50 um probe" comparison with Tarcsay et al.
(20-25 um probes) is wrong for the same reason: the probes have the same pitch.
